Token Radar ranks all 198 pre-token protocols in the DefiLlama snapshot by implied launch value — each one priced off the live-token market multiples in its own category — and gives every protocol a concrete seven-step farm plan with costs and times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
